FACES CADASTRADAS (JSON)

Recurso opcional. Só cadastre pessoas que autorizaram. O banco fica neste navegador, em JSON, com números derivados dos landmarks (nenhuma foto) e nada é enviado a servidor. O reconhecimento compara apenas com quem foi cadastrado e é aproximado: não use para segurança ou controle de acesso.

    Menor = mais rigoroso. A distância medida aparece em “Pessoa cadastrada”.

      COMO FUNCIONA

      Do pixel ao ponto de referência: o caminho de cada quadro de vídeo.

      1. 1. Câmera

        A câmera captura os frames em tempo real através da API getUserMedia.

      2. 2. Captura do frame

        Cada quadro do vídeo é entregue ao modelo dentro do próprio navegador.

      3. 3. MediaPipe

        O modelo analisa cada frame e procura uma face na imagem.

      4. 4. Face Landmarker

        O sistema localiza pontos de referência da face (478 por rosto, incluindo as íris).

      5. 5. Análise

        Os landmarks são utilizados para interpretar movimentos e características geométricas.

      6. 6. Visualização

        Os resultados são desenhados sobre o vídeo e nos painéis de estatísticas.

      TECNOLOGIA UTILIZADA

      O MediaPipe é uma plataforma desenvolvida pelo Google para aplicações de percepção e visão computacional. O Face Landmarker permite detectar landmarks faciais e outras informações relacionadas à face em aplicações compatíveis.

      Esta demonstração usa o pacote @mediapipe/tasks-vision (MediaPipe Tasks) e o modelo oficial face_landmarker.task, executados localmente no navegador via WebAssembly/WebGL.

      PRIVACIDADE E SEGURANÇA

      Todo o processamento da demonstração é realizado localmente no navegador sempre que possível. O sistema não precisa enviar a imagem da câmera para um servidor para realizar a demonstração.

      • Sem upload automático da câmera
      • Banco de rostos opcional, só local e só com consentimento
      • Identificação apenas de pessoas cadastradas por você
      • Sem armazenamento automático de imagens
      • Processamento local

      O navegador sempre solicita a sua permissão antes de acessar a câmera, e você pode revogá-la quando quiser. Arquivos do modelo e da biblioteca são baixados uma vez de CDNs públicas; nenhuma imagem sua é enviada.

      Powered by MediaPipe · Projeto educacional

      Esta aplicação demonstra detecção e rastreamento facial. O reconhecimento é opcional, aproximado, só compara com pessoas cadastradas com consentimento e não deve ser usado para segurança.

      Sobre o projeto

      Face Vision AI é uma demonstração educacional de visão computacional. Ele realiza detecção + landmarks + rastreamento + análise de movimento facial.

      O reconhecimento é opcional: compara apenas com pessoas que você cadastrar (com consentimento), guardadas em JSON neste navegador, como números e nunca como imagens. As capturas de frame só acontecem quando você clica em “Capturar frame” e são baixadas diretamente para o seu dispositivo.

      Tecnologias: HTML5, CSS3, JavaScript (ES Modules), Canvas 2D, getUserMedia e MediaPipe Tasks Vision.
